## 既知の制限

- 子への依頼は tmux の `send-keys` で入力するため、子が選択待ちの画面にいると保留になります。判定は画面の文字列（`Do you want`、`Allow`、`❯ 1.` など）に依存します。Claude Code の表示が変わると誤判定します
- `pm status` は課題ファイルの `- [ ]` を数えるだけです。子が形式を崩すと数が合いません
- 案件が `/mnt/c` 配下にあると、別ユーザー構成でも親から読めます
