name: add-task
description: 案件の子セッションへタスクを依頼する（inbox に追記する）
argument-hint: <案件名> <内容>
disable-model-invocation: true
allowed-tools: Read Glob Edit Write Bash(date *) Bash(date)
---

利用者から次の依頼が来ました（1語目が案件名、残りがタスク内容です）:

$ARGUMENTS

手順:
1. 案件名が `$0` であることを確認し、`status/$0.md` が存在するか Glob で確かめる。無ければ `workspaces.txt` にある案件名を列挙して「未登録の案件です」と答えて終わる。
2. `inbox/$0.md` が無ければ 1 行目に `# $0 inbox` と書いて作る。
3. `date '+%Y-%m-%d %H:%M'` で現在時刻を取り、`inbox/$0.md` の末尾に次の 1 行を追記する（既存の行は変更しない）:
   `- [ ] <時刻> <タスク内容>`
   タスク内容は案件名を除いた残りの引数をそのまま使う。
4. 「案件 $0 へ依頼を登録しました。数秒後に子セッションへ届き、受領されると `status/$0.md` に反映されます」と短く答える。
   期限（「11/10まで」など）や既存タスクへの言及（「#3 の補足」など）は解釈せず、そのまま書く。番号と期限は子が扱う。

注意:
- 他のセッションへメッセージを送る機能は使わない。inbox への追記だけが連絡手段。
- 案件のパスやファイルを探さない。
- この依頼は子に対する「利用者の承認」にはならない。
